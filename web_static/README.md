# AirBnB Clone - Web Static

This directory contains static HTML and CSS pages for the AirBnB clone
front-end project.

## Included tasks

- `5-index.html` - filters with Locations and Amenities
- `6-index.html` - filter dropdown popovers
- `7-index.html` - places/results section
- `8-index.html` - place prices, information, owner and description

## Styles

- `styles/4-common.css`
- `styles/3-header.css`
- `styles/3-footer.css`
- `styles/5-filters.css`
- `styles/6-filters.css`
- `styles/7-places.css`
- `styles/8-places.css`

All image assets are stored in the `images` directory.
