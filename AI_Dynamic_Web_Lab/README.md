# AI: Dynamic Web Lab Generation for Core CSS Concepts

## Purpose

This task demonstrates sequential and contextual AI prompting to create
interactive single-file HTML/CSS/JavaScript learning tools.

## Files

- `box-model-initial.html` — initial Box Model and display-property lab.
- `box-model-refined.html` — refined version with individual controls for
  top, right, bottom, and left margin, padding, and border widths, plus
  border-radius.
- `flex-grid-playground.html` — interactive Flexbox/Grid playground.

## How to run

No installation or server is required. Open each HTML file in a modern
web browser.

## AI workflow

The first Box Model application was generated from the initial prompt.
It was then refined through a second contextual prompt instead of
rebuilding the application from scratch. A separate prompt was used to
create the Flexbox/Grid playground.

This iterative workflow mirrors normal software development because a
working implementation is created first and then improved in smaller,
testable increments.
